# TypeScript LSP 플러그인 상세 기능

## 1. 제공 기능 목록

| 카테고리 | 기능 |
|---------|------|
| **진단** | 타입 에러, 문법 오류, 린팅 경고 실시간 감지 |
| **네비게이션** | Go to Definition, Find References, Hover 정보 |
| **인텔리전스** | 자동 완성, 타입 정보, JSDoc 문서 표시 |
| **리팩토링** | 심볼 이름 바꾸기, Quick Fixes, 자동 import |

## 2. 동작 방식

```typescript
// 예: 타입 오류 감지
const tokenCount: number = "100";
// → LSP가 즉시 감지: "Type 'string' is not assignable to type 'number'"

// 예: 자동 완성
const stats = useMemo(() => {

```

## 3. Claude가 활용하는 방식

**중요**: LSP는 **백그라운드에서 자동으로** 작동합니다.

- Claude가 코드를 **작성/편집할 때** → 실시간 오류 피드백
- Claude가 파일을 **읽을 때** → 타입 정보 참고
- **명시적 도구 호출은 불가** → Go to Definition 등은 직접 호출 불가

## 4. 사용자가 체감할 수 있는 효과

| 효과 | 설명 |
|------|------|
| **버그 조기 발견** | 빌드/실행 전에 타입 오류 감지 |
| **코드 품질 향상** | 사용하지 않는 변수, 잘못된 의존성 배열 경고 |
| **리팩토링 안전성** | 변수명 변경 시 영향 범위 파악 |
| **개발 속도** | 오타, 잘못된 props 전달 즉시 감지 |

## 5. 한계

```
┌─────────────────────────────────────────────────┐
│  LSP 플러그인이 제공하는 것                      │
│  ✅ 실시간 진단 (에러/경고)                      │
│  ✅ Claude 코드 작성 시 타입 정보 참고            │
│                                                 │
│  LSP 플러그인이 제공하지 않는 것                  │
│  ❌ Claude가 "Go to Definition" 도구로 호출      │
│  ❌ Claude가 "Find References" 도구로 호출       │
│  ❌ MCP 도구처럼 명시적 호출                     │
└─────────────────────────────────────────────────┘
```

LSP는 **자동화된 백그라운드 지원**이며, Claude가 직접 호출하는 도구가 아닙니다.
