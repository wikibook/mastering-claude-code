# ch03-first-vibe — 바이브 코딩 첫걸음

**관련 장:** 3장 (바이브 코딩 기초)

한 줄 프롬프트만으로 빠르게 결과물을 만들어 보는 첫 번째 바이브 코딩 실습입니다. 터미널 스타일의 포트폴리오 페이지를 단일 `index.html`로 생성합니다.

## 무엇을 배우나요

- 클로드 코드에게 한 줄 프롬프트로 작업을 요청하는 감각
- 별도 설정 없이 결과물을 즉시 확인하는 흐름

## 구성

```
ch03-first-vibe/
└── index.html   # 단일 파일 정적 페이지
```

## 실행 방법

별도 빌드가 필요 없습니다. 파일을 브라우저로 열면 됩니다.

```bash
open index.html        # macOS
# 또는 파일을 더블클릭
```
