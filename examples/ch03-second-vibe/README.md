# ch03-second-vibe — 바이브 코딩 실습

**관련 장:** 3장 (바이브 코딩 기초)

기술 스택과 UI를 구체적으로 요청하는 프롬프트로 만든 두 번째 실습입니다. "모던 사이버펑크 터미널" 콘셉트의 인터랙티브 개발자 포트폴리오로, 터미널 명령어를 입력하는 방식의 인터페이스를 제공합니다.

## 무엇을 배우나요

- 기술 스택·디자인·동작을 구체적으로 명시하는 프롬프트 작성법
- 여러 파일(HTML/CSS/JS)로 구성된 결과물을 다루는 방법

## 구성

```
ch03-second-vibe/
├── index.html    # 터미널 창 구조
├── styles.css    # 사이버펑크 테마 (글래스모피즘, 네온 글로우)
├── script.js     # 터미널 명령어 시스템
└── CLAUDE.md     # 프로젝트 가이드
```

## 실행 방법

별도 빌드가 필요 없습니다. 브라우저로 열면 됩니다.

```bash
open index.html        # macOS
```

페이지에서 `help` 명령을 입력하면 사용 가능한 커맨드를 볼 수 있습니다.
